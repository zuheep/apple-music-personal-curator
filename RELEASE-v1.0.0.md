# Apple Music Personal Curator v1.0.0

First public release of **Apple Music Personal Curator** — a reusable AI curation workflow for personalized Apple Music playlists.

## Highlights

- Multi-cluster Taste Profile instead of a single genre label.
- Separate long-term taste, short-term context, explicit dislikes, and listening fatigue.
- Controlled exploration with reliable, adjacent-discovery, and serendipity budgets.
- Four-act sequencing: Entrance → Expansion → Discovery → Landing.
- Artist / genre saturation and repetition controls.
- Apple Music catalog grounding and version verification.
- Reflective retry instead of falling back to generic hits.
- Immersive playlist titles and narrative design.
- Natural-language feedback loop for ongoing taste learning when the host platform supports it.
- Privacy and memory boundaries for portable use across AI assistants.

## ChatGPT installation

Download `apple-music-personal-curator-v1.0.0.zip`, then in ChatGPT open **Plugins → Skills → Create → Upload from your computer** and select the package.

Feature availability can depend on the user's ChatGPT plan, workspace settings, and connected music services.

## Daily automation

The README includes a ready-to-copy prompt for creating a recurring daily Apple Music curation task after the Skill is installed.
