# Example Prompts

## Daily playlist

```text
给我今天的 Apple Music 歌单。今天下午需要专注工作，不想太吵，但不要纯氛围音乐。熟悉感 60%，发现感 40%。
```

## Feedback-driven update

```text
昨天第 3、6、11 首很好，第 8 首太精致、太“制作感”了。今天沿昨天的方向继续，但陌生度提高一点。
```

## Avoid recommendation collapse

```text
我喜欢 Coldplay，但最近听腻了。不要给我一串 Coldplay 相似艺人。沿旋律写作、钢琴/吉他质感、情绪推进和年代关系向外探索。
```

## Multi-cluster taste

```text
我同时喜欢 Radiohead、宇多田光、陈绮贞和 90 年代 trip-hop。不要强行把它们归成一个风格，做一张能把几个兴趣连接起来的歌单。
```

## Strong narrative request

```text
做一张适合晚上独自坐火车的歌单。标题和叙事要像真正的音乐策展，不要逐首写推荐理由。
```
